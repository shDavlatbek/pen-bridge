First release of PenBridge. It turns a **Samsung Galaxy S24 Ultra + S Pen into a drawing tablet** for Windows, set up for **Clip Studio Paint**.

## Downloads
| File | For |
|---|---|
| **PenBridge-0.1.0.apk** | Phone app (Android 10+) |
| **PenBridge.exe** | Windows 10 (1809+) / Windows 11 program |

## Quick start
1. Run `PenBridge.exe` on the PC and keep its window open. If Windows warns you, click *More info → Run anyway*. Allow it on **Private networks** when the firewall asks.
2. Install `PenBridge-0.1.0.apk` on the phone and open it.
3. Connect the phone and PC to the same Wi‑Fi. They connect automatically.
4. In Clip Studio Paint: **File → Preferences → Tablet → Tablet service = TabletPC**, then restart it.

USB cable setup and troubleshooting are in the [README](https://github.com/shDavlatbek/pen-bridge#readme).

## What's included
- Pen pressure, hover, tilt (if the S Pen reports it), and palm rejection
- 10 shortcut buttons (tap buttons, plus hold buttons for Pan, Rotate and Pick color) and a scroll dial (brush size, zoom, undo/redo, layer)
- S Pen side button: hold to erase by default, configurable
- Left-handed layout, pressure feel, monitor choice and fully editable shortcuts
- USB (via adb) or Wi‑Fi with automatic discovery

## Known limitations
- Windows only for now. Mac and Linux are planned.
- First version: it hasn't been tested on a real phone and PC yet. Please report problems in [Issues](https://github.com/shDavlatbek/pen-bridge/issues).
- The app isn't code-signed, so Windows SmartScreen shows a warning the first time.
